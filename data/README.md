# 示例数据

五本已完成 notebook 在初始化或各模板内生成自己的数据，不需要下载文件。

- 01 使用小型、易手算的表来展示 API 行为；它们不是市场行情。
- 02 的 A 部分使用固定随机种子的多实体时间序列，包含趋势、不同波动阶段和日历效应，并另建有缺行/缺值/重复问题的练习副本。
- 02 的 B 部分每个可视化案例独立使用 8–10 行小表，先展示全部输入，再给任务与短代码。每例的表格和示例建表代码来自同一份数据定义；使用自己的同列名 `df` 时可跳过示例建表。
- 02b 美观版沿用 02 基础可视化的同一批小表，只改变绘图样式，便于直接对照。
- 03 回测手册每例创建独立的合成价格、仓位、指令或每日收益表，先 `display(df)` 再解释回测和展示结果。数据用于核对时点和资金记账，不是训练得到的策略或真实回测。B16 为缩短月度示例，明确假设省略日期的收益已验证为零；实际数据需要检查完整会话日历。
- 04 机器学习手册每例用固定随机种子创建约140–270行的 DataFrame，展示前8–9行及总行数。部分数据人为包含线性或非线性预测关系，仅为演示模型 API。大部分特征假设盘前已知、目标为同日开盘到收盘收益；M01 / M11 / M12 构造未来收益标签并标记实现时点。合成目标不是公开行情数据，不能把模型结果当作市场证据。
- 生成过程中的阶段或异常标签仅用于教学解释；不是可以提前知道的真实预测特征。
- 合成业务日日历不冒充真实交易所日历。用于真实数据时需要替换成相应会话或采样时间表。

所有输入字段和单位写在 notebook 开头，每个场景还会再次说明所需字段。
不要把模板生成的统计关系当作市场证据。原始值、加工值与审计报告分开保存，不直接覆盖原始输入。

## 可选真实数据

```bash
python scripts/download_french.py --start 2010-01-01 --end 2025-12-31
```

从 [Kenneth French 官方网站](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_30_ind_port.html) 下载 30 个行业的市值加权日收益。
脚本只选择 `Average Value Weighted Returns -- Daily` 表，识别官方缺失编码，将百分数除以 100 得到 `ret`，不会填补缺失。
字段为 `date, asset, return_pct, ret`；不是实际可交易证券的价格/成交量。
提供方会修订历史，该快照不能替代 point-in-time 数据；脚本保存来源、下载时间、原文件哈希和原始表头。

下载结果位于已忽略的 `data/downloads/`，不随本仓库重新分发。第三方数据许可与本仓库代码许可分开，使用前请查阅数据提供方的说明。
用户自己的数据请放入已忽略的 `data/local/`。
